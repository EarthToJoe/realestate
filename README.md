# realestate

Software that does what a New York real estate agent does, with the human and licensed steps made visible.
Research plan plus proof of concept, Hudson Valley first.

- Joe's brief (source of truth): `docs/BRIEF.md`
- What "done" means: `docs/SUCCESS-CRITERIA.md` (needs sign-off)
- Riskiest assumptions and kill criteria: `docs/ASSUMPTIONS.md`
- Decisions: `docs/DECISIONS.md` · Questions for Joe: `docs/QUESTIONS-FOR-JOE.md`
- Research deliverables: `docs/research/` (notes with sources in `research_notes/`)
- Daily progress: `docs/PROGRESS.md` · Spend: `docs/SPEND-LOG.md`
- Session rules: `CLAUDE.md` · VPS setup: `scripts/vps-setup.sh`

## The demo app (proof of concept)

Build spec: `docs/specs/poc-architecture.md`. Live at https://realestate.hughesnode.com (house login); the review
pages keep their old addresses beside it.

    make venv && make test        # Python 3.12 + uv; fast tests on the fake model provider
    make run                      # http://127.0.0.1:8000; live AI if the key file is readable, else replay
    make docker-build             # the image hughesnode runs

Code map: `app/main.py` (app factory), `app/records/` (the record service and `catalogue.yaml`, every marker's
text), `app/model/` (`ModelProvider` live/replay/fake, `AgentContext(side)`), `app/modules/<step>/` (one package per
step), `app/demo/steps.yaml` (step list, narration cards and `docs/DEMO-SCRIPT.md`, generated by
`scripts/gen-demo-script.py`). Hosting: `scripts/hosting.sh` (`redeploy` after code changes, `check` for the live
URL); `scripts/live-flow.sh` walks the built steps on the live site.
